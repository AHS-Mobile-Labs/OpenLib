# Changelog

## 2026-06-14

### Added

- Expanded feature documentation for app pages, search and discovery, reviews, edit requests, reports, roles, accounts, organizations, moderation, ownership claims, verification, and release workflow.
- Dedicated [Roles and Permissions](/docs/roles-and-permissions) guide explaining User, Contributor, Maintainer, OpenLib Team, and Admin responsibilities.
- Documentation for safety reporting, ownership claims, verification badges, organization-owned apps, and release checks.

### Updated

- Updated the [Getting Started](/docs/getting-started) documentation map so new users can find the expanded feature docs.

## 2026-06-13

### Added

- Built-in OpenLib documentation portal under `/docs/`.
- Markdown-based documentation source in `docs/content/`.
- Generated clean URLs, metadata, sitemap entries, and search index.
- Documentation search, table of contents, breadcrumbs, reading time, last updated dates, status badges, previous/next navigation, and copy buttons for code blocks.
- Local Markdown documentation workflow with generated static pages.
- Screenshot assets copied from `docs/assets/` into generated docs output.
- Expanded docs with detailed usage, contribution, review, taxonomy, and publishing workflows.
